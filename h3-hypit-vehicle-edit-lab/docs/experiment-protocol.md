# 车辆属性编辑实验协议

## 1. 假设与素材

依次检验全车外观、全车结构、局部外观和局部几何。每次只指定一个编辑目标。定位「哪个镜头里的哪个对象」属于模板；向量编辑能否产生足够局部的变化，靠配对对照检验。

| 属性 | 优先镜头 | 目标命中 | 优先检查的副作用 |
| --- | --- | --- | --- |
| 车漆 | 车身大面积可见的外景，正侧或侧前方优先 | 蓝色出现在主要可见车漆区域并贯穿可见区间 | 背景整体色偏、模型改变车身形状、阴影或反射被误判为车色变化 |
| 车型 | 能看出整体比例、门数和车身高度的远景或中景 | 盲评能识别为 SUV；车身比例与类别相符 | 车色或道路漂移、司机消失、行驶方向和镜头运动变化。轮拱和车顶为车型改变允许涉及的结构 |
| 轮毂 | 侧前或侧后近景，目标轮面至少在三个抽样时刻清晰 | 目标轮位可认出网格辐条结构，多帧保持，无遮挡时其他可见轮位一致 | 轮胎冒充轮毂改变、轮径或轮位漂移、轮辐随帧变形、车漆或窗线漂移 |
| 后侧窗 | 侧视或侧后方中近景，后侧窗和车身锚点清晰 | 后侧窗的后缘角度与轮廓向目标梯形变化，多帧保持 | 车门或车顶重画、玻璃颜色变化、轮毂样式漂移、整车换型 |

轮毂和车窗的正反例要用可辨认的参考图定义。位置评审可记录轮圈边界、后侧窗轮廓与车门、车顶等固定锚点。ROI 是输出端的测量区域；使用遮罩参与生成时，要把它记录为一个额外输入。首轮细节镜头的画面分辨率以能看清目标为准，所有配对组保持一致；后续再增加转动、遮挡、远景和强反光作为难例。

## 2. 对照组

同一母版下，每个样本使用匹配的 checkpoint、VAE、编码器、工作流、采样器、步数、调度、分辨率及实际初始噪声。记录文本条件与视觉条件各自对应的输入和哈希。每个实验组单独出片和记录，保留对照组的输出。

| 组 | 改动 | 回答的问题 |
| --- | --- | --- |
| A0 基线重放 | 原条件包、原视觉条件和原实际初始噪声 | 复现实验条件是否可靠？有可比的原始解码结果时对照帧和音频哈希；基线无法复现的样本先查清原因 |
| A1 纯向量 | 只应用冻结的目标方向和强度，视觉条件及噪声沿用 A0 | 改张量能否命中这个属性？变化是否足够局部？生成端无需原始或新 prompt |
| A2 随机方向 | 同一张量位置施加固定随机种子、与 A1 扰动等范数的方向 | 目标命中能否和无关扰动区分？ |
| A3 向量 + 首帧同步 | 保持 A1 的文本方向，用前一变体镜头的新末帧更新存在依赖的后续镜头视觉条件 | 同步能否改善接缝？单独核对负责文本条件的张量；若工作流重算了它，记录差异和原因 |
| A4 参考媒体重生成 | 根据目标属性，给 H3 目标参考图、必要的原镜头片段和固定编辑指令。按已支持的 H3 模式选择输入组合 | 经过显式媒体引导能做到什么？模型模式或 checkpoint 与纯向量组不同时，单独分层报告 |

## 3. 运行顺序

1. **方向构建。** 为每个属性准备至少三对只改该属性的条件样本。以现有的条件行均值差方向作为首个基线，并记录 donor 对、方向范数和强度。轮毂、车窗各有独立方向。训练方向时可以用成对文字，生成验收组只加载条件包及方向。
2. **探索。** 每种属性先用清晰的镜头、三个噪声种子跑 A0/A1/A2，并用 A4 做参考上限对照。用探索组选择方向和强度。轮毂、车窗先在停驶或慢速的镜头上验证，再提高速度和角度难度。
3. **独立验收。** 每种属性另取三个未用于探索的母版镜头，每镜头三个新种子，形成九组配对对照。冻结方向、强度和评审标准。四项共 36 个验收配对，分别报告结果，避免强项掩盖弱项。
4. **分镜验收。** 用一对具有真实首尾帧依赖的镜头对照 A1 和 A3。按实际帧边界，在接缝前后各检查 0.5 秒。车色先复现已知问题；细节进入这一步的前提是目标在接缝附近可见。
5. **可选联合变体。** 两项各自通过后，再试车色 + 轮毂、车型 + 车窗。记录叠加是否造成新的副作用，独立于单项结果。

如果轮毂或车窗在探索组中反复带动车型变化，可以增加两种诊断：第一种是在探索数据上对相关条件行分组施加不同权重，观察非目标区域的变化，再冻结后用新样本验证；第二种是用固定参考帧、局部编辑或遮罩引导，检验目标形状能否由视觉输入控制。前一种仍属于条件张量编辑，后一种作为额外视觉干预记录。相同的 token 行或输出区域能否跨样本复用，需要分别验证。

## 4. 评审与通过线

- **单样本。** 预先从基线选三个目标清晰的时刻。把基线和变体对齐检查，并浏览整段排查闪烁。记录目标命中、时间稳定、非目标保护和接缝结论。车型的结构联动按上表列出的允许项判定。
- **局部细节。** 对轮毂和车窗保存原帧及带相同锚点的局部裁剪。使用可获得的蒙版或轮廓检查修改覆盖范围；目标在基线清楚、变体却变糊或被遮住，记为未通过。基线本身不可见的样本在开始前标记阻塞，先补齐同规格样本。
- **盲评。** 随机打乱组别，至少两名评审按同一套正反例判断。分歧要标记并复核。对接缝同时检查目标属性、车的身份和动作是否连续。
- **首轮通过线。** 单个样本须同时达到目标命中、时间稳定及保护项达标。每个属性九个独立样本至少八个通过，A1 的目标命中率须高于 A2。接缝和联合编辑各自报告。所有分母、预先排除样本、随机扰动的种子与未通过案例都保留。
- **成本。** 记录实际 H3 生成次数、每镜头用时、复用产物数量和合成用时。同一条件包的精确命中、未变镜头的素材复用、GPU 推理内部缓存各自记账。
