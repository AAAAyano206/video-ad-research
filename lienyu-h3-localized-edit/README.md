# MiniMax H3 车辆区域及原镜头约束实测

本实验在 ModelArts 上使用 MiniMax H3，复用上一轮 9 个车漆留出镜头和 9 个车型留出镜头。每项覆盖三个场景和每场景三个 seed。所有 H3 模型请求使用原包中的实际视频和音频噪声，工作流没有原 prompt 或文本编码节点。

| 组别 | 处理 |
| --- | --- |
| A0 | 原条件包重放，以现有画面为共同参考 |
| A1 | 冻结的目标方向与强度，复用上一轮纯向量结果 |
| A2 | 等范数随机方向，复用上一轮对照 |
| M1 | A1 条件包，加入逐帧车辆区域和每步原镜头轨迹约束 |
| M2 | A2 条件包，加入同样的区域与轨迹约束 |
| P3（仅车漆） | 分割原车，在原镜头像素上迁移 A1 生成的车漆主色相 |
| P4（仅车漆） | 同 P3，颜色来自 A2，使用同一算法 |

H3 每步后的原镜头潜变量由 T0 重放记录。新的 H3 请求和 T0 比对采样时间表和实际起始张量。对 M1 和 M2，H3 Turbo 先完成原有的采样器更新，再把区域外的潜变量和音频潜变量复制回同一步的 T0 状态。视频 VAE 以 5 个潜时间位置为一个 17 帧分块，蒙版映射到该分块并包括有限时间邻域。车色和车型区域在模型网格上分别扩大 1 和 2 格，允许车型类变化所需的车顶、轮拱和高度变化。VAE 解码仍可能使改动车辆的影响传到掩码边缘。

P3/P4 是 H3 结果和原始像素的组合实验。分割工具只看原镜头。算法以车周围的高色度像素投票，从 H3 候选中提取最显著的色相，不指定目标蓝色。原片亮度和车身形状保留，色相只在分割出的原车漆上转移，音频直接沿用原片。重新压制视频会引入轻微量化差异。该组无额外 H3 推理调用，已计入提供颜色的 H3 纯向量生成。

## 执行及核查

- `segment.py` 输出原镜头的逐帧蒙版。权重来自 Ultralytics YOLO11n-seg v8.3.0，SHA-256 为 `55ed65c56c91713d23e8402371c6c49a6fd84f257f7dce452e8d70e41dcbe152`。依赖只安装在实验副本的 `dependencies`。
- `H3_SEGMENTED=1 bash worker.sh paint` 和 `H3_SEGMENTED=1 bash worker.sh body` 分别运行各阶段 H3 推理。实验 worker 使用副本及独立端口。退出时恢复短期借用的空闲 4 号服务实例，其他服务实例继续提供服务。
- `paint_transfer.py --segmented` 用已有 H3 对照视频完成 P3/P4。
- `prepare_review.py paint --segmented` 和 `prepare_review.py body --segmented` 生成去元数据的盲评片、12 个时间点的对齐画面和独立的组别密钥。
- `summarize_review.py results/review-paint` 和 `summarize_review.py results/review-body` 汇总独立评分。未知和未通过都不计入通过。目标命中、时间稳定、车身或允许的 SUV 几何、场景、镜头、其他受保护特征均通过，才算严格通过。沿用上一轮九条至少八条严格通过的验收线。

调试产物 R1/R2（未对齐 H3 真实时间分块）、L1/L2（红色阈值粗区域）、P1/P2（粗区域迁移）保留在远程实验目录。正式盲评组由同一套精确车辆检测生成。比较分母始终是同一批 9 条按属性区分的母版。精确分割是在看到粗区域外溢后增加的，本批对照测量该修正的效果，跨素材的泛化需以全新的广告检验。

## 实测结果

两路独立 AI 盲评分别覆盖 54 个车色候选和 36 个车型候选。全部 14 个字段分歧已对照原片复核。

| 属性与干预 | 目标命中 | 稳定命中 | 严格通过 |
| --- | ---: | ---: | ---: |
| 车漆纯向量 A1 | 9/9 | 9/9 | 0/9 |
| 车漆车辆区域与 H3 去噪轨迹 M1 | 9/9 | 9/9 | 0/9 |
| 车漆分割与原片迁移 P3 | 9/9 | 2/9 | 0/9 |
| 车型纯向量 A1 | 9/9 | 9/9 | 0/9 |
| 车型车辆区域与 H3 去噪轨迹 M1 | 9/9 | 6/9 | 0/9 |

各等强度随机对照的目标命中均为 0/9。P3 有 9/9 在命中蓝漆的同时保住车身、场景和镜头。七条存在尾翼或可见车漆漏染，其余两条改动了车窗、轮胎附近的原有反光或刹车卡钳等受保护细节。车型 M1 的车辆区域明显降低了背景漂移，但九条均未保住原相对机位和原红漆，三个博物馆样本还出现 SUV 缺失或变形等时序问题。

原车区域外逐帧差异大于 20/255 的像素比例，车色各样本的中位数由 A1 的 83.55% 降至 M1 的 18.43% 和 P3 的 0%。车型 A1 和 M1 对应为 88.07% 和 34.47%。测量时，逐帧原车蒙版外围 11 像素也从背景统计剔除。

## 工程意义与后续

这个工程建立了两种区域干预的对照。采样步锁定能压低区域外变化，像素迁色能在更大程度上继承原车身和机位。车型 M1 的观察说明区域框无法单独保证原来相机和车辆的相对关系。车漆结果则把下一阶段问题缩小到像素级部件保护、遗留红漆、暗部及反光。 [部件换色及留出实验](../lienyu-h3-ad-workbench/README.md)
